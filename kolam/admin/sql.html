Jalankan 1. Kolam Koi dulu, baru 2. Kasir Koi.

  1. Ketuk tombol hijau di atas.
  2. Kembali ke Supabase → SQL Editor, hapus isi lama.
  3. Tekan lama di area kosong → Paste → Run.

Kalau tombol tidak berhasil: ketuk kotak di bawah, pilih Select All, lalu Copy.
